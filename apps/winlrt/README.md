# WinLRT — monorepo kökü

**WinLRT** = kullanıcıların indirdiği çok platformlu `.ltr` istemcisi (WinRAR rolü, LTR formatı).

| Dizin | Platform | Durum |
|-------|----------|--------|
| [desktop/](./desktop/) | Windows + macOS (Tauri) | W1–W2 |
| [mobile/](./mobile/) | Android + iOS (Expo) | W3–W4 |

Paylaşılan mantık: `@nakliyeborsasi/core/ltr`.

Yol haritası: [docs/WINLRT_PRODUCT_ROADMAP.md](../../docs/WINLRT_PRODUCT_ROADMAP.md)
