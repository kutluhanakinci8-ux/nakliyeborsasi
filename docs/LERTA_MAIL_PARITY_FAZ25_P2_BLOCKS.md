# Parite Faz 25 — P2 kurumsal HTML blokları

Zengin editör kütüphanesi (`apps/mail-web/src/lib/mailComposeHtmlBlocks.ts`):

| Blok | Açıklama |
|------|----------|
| Hero | Marka rengi ile başlık bandı |
| Logo üst bilgi | HTTPS logo + başlık |
| CTA düğme | Marka rengi arka plan |
| Yasal dipnot | Kurumsal dipnot satırı |
| Ayırıcı | Yatay çizgi |
| İki sütun | Yan yana metin |
| Bilgi / başarı / uyarı kutusu | Callout varyantları |
| Alıntı | İtalik alıntı + kaynak |
| Özellik satırı | ✓ + başlık + açıklama |
| Görsel (URL) | Responsive img |

Webmail **Yaz** ekranında **HTML blok** açılır listesi ve araç çubuğu; tenant **marka rengi / logo / yasal dipnot** compose’a otomatik bağlanır (Ayarlar → Hesaplar → Kurumsal kimlik).

Durum: **✅ kod** (Kurumsal+ Enterprise marka; Enterprise tam chrome gizleme).
